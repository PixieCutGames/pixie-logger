# Technical Spec — Phase 3, Task 5: Integration in Taqa (local only)

> **Prerequisite:** [04-build.tech.md](04-build.tech.md) is done and `pnpm --filter @pixie-logger/logger pack:local` has produced a `.tgz`.

Design reference: [05-integration.md](05-integration.md).

This task runs in the **Taqa repository**, not pixie-logger.

## Rules for the agent

1. **Never commit, push, stash-drop or reset anything in the Taqa repo.** All changes are local and will be discarded by the user.
2. Before changing anything, run `git status` in Taqa. If the working tree is not clean, **stop and report**; don't mix test changes with the user's work.
3. Change as little as possible. Allowed changes: `package.json` / lockfile (via the package manager), the new logger file, one import at app startup, one router hook, and native project files only as regenerated by `npx cap sync`.
4. **Do not log any personal or client data:** no user names, roles, emails, IDs, tokens, form values, API responses or real URLs containing IDs. Only the fixed test events defined below.
5. **Do not handle the API key.** Leave the placeholder `'PASTE_TAQA_LOCAL_KEY_HERE'`; the user pastes it.
6. Don't run on devices or change signing, app IDs or native settings.
7. Finish by running "Verification" and reporting the output, plus a list of every file changed.

## Step 1 — Inspect and report

Report before continuing:
- Framework: Angular (check for `@angular/core`) or React (`react`), and their major versions.
- Package manager: from the lockfile (`package-lock.json` → npm, `pnpm-lock.yaml` → pnpm, `yarn.lock` → yarn).
- Capacitor major version (`@capacitor/core`), and whether `@capacitor/app` and `@capacitor/preferences` are installed.
- The app's entry file (`src/main.ts` / `src/main.tsx`) and router setup.
- The TypeScript `moduleResolution` setting.

If the framework is neither Angular nor React, stop and report.

## Step 2 — Install

With Taqa's package manager:
1. The logger `.tgz` by absolute path (the user gives the path, or find it in `<pixie-logger>/packages/logger/`).
2. `@capacitor/app` and `@capacitor/preferences` **only if missing**, at the major version matching `@capacitor/core`.
3. If step 2 installed anything, run `npx cap sync`.

## Step 3 — Logger file

Angular: `src/app/pixie-logger.ts`. React: `src/pixie-logger.ts`.

```ts
import { Capacitor } from '@capacitor/core';
import { App } from '@capacitor/app';
import { Preferences } from '@capacitor/preferences';
import { createLogger } from '@pixie-logger/logger';
import { capacitorLifecycle, capacitorPlatform, capacitorStorage } from '@pixie-logger/logger/capacitor';
import { webLifecycle } from '@pixie-logger/logger/web';

const platform = capacitorPlatform(Capacitor);

export const logger = createLogger({
  endpoint: 'https://pixie-logger.<subdomain>.workers.dev/v1/logs',   // user fills in
  apiKey: 'PASTE_TAQA_LOCAL_KEY_HERE',
  appVersion: '<read from package.json version, or "0.0.0-local">',
  platform,
  storage: capacitorStorage(Preferences),
  lifecycle: platform === 'web' ? webLifecycle() : capacitorLifecycle(App),
  flushIntervalMs: 5000,
  debug: true,
});

/** Dev helpers, callable from the browser / remote-debugging console. */
const pixieTest = {
  info: () => logger.info('pixie_test_info', { message: 'manual info event' }),
  error: () => logger.error('pixie_test_error', { context: { error: new Error('deliberate test error') } }),
  redaction: () => logger.info('pixie_test_redaction', { context: { password: 'x', userEmail: 'y', ok: 'visible' } }),
  burst: (n = 30) => { for (let i = 0; i < n; i++) logger.debug('pixie_test_burst', { context: { i } }); },
  badName: () => logger.info('Bad Name'),
  flush: () => logger.flush(),
  session: () => logger.sessionId,
};
(globalThis as unknown as { pixieTest: typeof pixieTest }).pixieTest = pixieTest;
```

- Fill `endpoint` with the placeholder subdomain text left as-is if unknown, and tell the user.
- For `appVersion`, use a literal string; don't import `package.json` if the project's TS config doesn't allow JSON imports.

## Step 4 — Startup and route events

**App started:** in the entry file, after the app bootstraps, add:
```ts
import { logger } from './app/pixie-logger';   // adjust path
logger.info('app_started');
```

**Route changes**, logging the **route pattern**, never the real URL:

- Angular: in the root component (or wherever `Router` is already injected), subscribe to `NavigationEnd` and log `logger.info('route_changed', { route })`, where `route` is built from the activated route snapshot: walk `router.routerState.snapshot.root` down `firstChild`, collect each `routeConfig?.path` that isn't empty, and join with `/` (prefix `/`). This yields e.g. `/auctions/:id`. Unsubscribe on destroy.
- React (React Router): in the top-level layout, use `useLocation` + `matchRoutes(routes, location)` to get the matched pattern and log it in a `useEffect` on `location.pathname`. If the router setup makes this hard, log only on mount and report.

## Verification

1. The project's normal build command (e.g. `npm run build` / `ng build`) succeeds. Report any warnings that mention `@pixie-logger`.
2. The project's type check / lint (if a script exists) passes or has no new errors.
3. Start the dev server (`ionic serve --no-open` or the project's equivalent) in the background, fetch the page with curl to confirm it serves, then stop it. Don't open a browser.
4. `git status` in Taqa: list every changed or new file.
5. `git diff --stat`.

Then tell the user what to do next (from [05-integration.md](05-integration.md)): paste the key and endpoint, run the app, and use `pixieTest.*` in the console for the test checklist.

## Done when

- Taqa builds with the logger installed, the logger file and two hooks are in place, and the change list has been reported.
- Nothing was committed.
